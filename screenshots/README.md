# Loan Approval Analysis — Dashboard Screenshots

This folder contains screenshots from the seven-page Power BI dashboard developed for the Loan Approval Analysis project.

## Dashboard Pages

1. **Executive Overview** — Overall loan application and approval metrics.
2. **Applicant Demographics** — Approval patterns across applicant demographic groups.
3. **Financial Insights** — Applicant income and loan-related analysis.
4. **Property and Location Analysis** — Approval patterns across property areas.
5. **Credit Risk Analysis** — Approval patterns associated with credit history.
6. **Combined and Advanced Insights** — Combined analysis of selected applicant characteristics.
7. **Key Insights and Recommendations** — Summary of the main findings and potential areas for further investigation.

The screenshots are provided to help viewers understand the dashboard layout and key analytical findings without opening Power BI Desktop.

**Note:** The observations shown in the dashboard describe patterns in this dataset and do not establish cause-and-effect relationships.
